# 사용설명서 작성 지침 (Phase 7)

요구사항은 "이 시스템을 전혀 모르는 사람도 이해하고 사용할 수 있게" 입니다. 그 기준을 만족하려면 명령어 목록만으로는 부족합니다. **개념을 먼저 납득시켜야** 합니다.

Phase 7 에서 `README.md` 를 이 구조로 다시 씁니다. 지금 미리 쓰지 마세요. CLI 가 확정된 뒤에 실제 출력을 붙여야 정확합니다.

---

## 독자 가정

- 프로그래밍을 모릅니다
- 터미널을 열어본 적이 거의 없습니다
- 이 프로그램이 자기 문제를 어떻게 푸는지 아직 모릅니다
- 매일 아침 5분 쓰려고 왔지 공부하러 온 게 아닙니다

이 독자에게는 "왜"가 "어떻게"보다 먼저입니다.

---

## 구조

### 1. 이 프로그램은 무엇인가

세 문장 이내. 그리고 실제 출력 화면 하나.

> 매일 누가 무슨 일을 할지 자동으로 정해주는 프로그램입니다. 사람과 작업을 한 번 등록해두면, 아침에 명령어 하나로 오늘의 배정표가 나옵니다. 누가 쉬는지만 알려주면 나머지는 알아서 처리합니다.

### 2. 5분 만에 시작하기

다운로드 → 압축 해제 → 실행 → `sched today`. 샘플 데이터가 들어 있으므로 아무것도 설정하지 않아도 결과가 보여야 합니다. **첫 성공 경험이 5분 안에 나와야 합니다.**

### 3. 개념 이해하기 ← 가장 중요한 장

여기서 독자를 잃으면 나머지가 소용없습니다. 그림 한 장과 실제 사례로 설명합니다.

설명할 순서:

1. **작업자** — 일할 사람. 쉬운 개념이므로 먼저.
2. **작업** — "청소기 돌리기, 2명 필요". 여전히 쉬움.
3. **작업 집합** — 여기가 고비입니다. "왜 그냥 작업 목록이면 안 되는가"에 답해야 합니다.
   > 청소기, 밀대, 소독, 정리는 함께 나눠 맡는 일들입니다. 4명이 있으면 이 넷을 4명에게 골고루 나눠야 하죠. 이렇게 "한 묶음으로 놓고 사람들에게 분배하는 단위"가 작업 집합입니다. 배치구역은 별도 집합이라 청소와 따로 계산됩니다.
4. **작업 분류** — "화면에서 묶어 보여주기 위한 것일 뿐, 배정에는 영향 없음"을 분명히.
5. **시간대** — 하루를 오전·오후로 나누고 각각 다른 분류를 붙인다.

여기서 예시 구성(평일 오전/오후, 주말)을 실제 데이터로 끝까지 보여줍니다.

### 4. 처음 설정하기

작업자 등록 → 작업 만들기 → 시간대 배치. 각 단계마다 입력할 명령어와 **그 직후 나오는 화면**을 함께 보여줍니다. 화면 없이 명령어만 나열하면 자기가 제대로 했는지 알 수 없습니다.

### 5. 매일 쓰는 법

실제로는 이 세 개만 씁니다. 앞에 두세요.

```
sched now              지금 할 일
sched today            오늘 전체
sched off add --worker 김철수 --today    누가 오늘 쉼
```

### 6. 자주 겪는 상황

문제를 독자의 말로 씁니다. `unassigned` 같은 용어가 아니라 "빨간 글씨로 미배정이라고 떠요".

- 미배정이 떴어요 → 사람보다 자리가 많은 상황. 왜 자동으로 안 채우는지, 어떻게 할지
- 사람이 갑자기 빠졌어요 → 급휴 등록, 왜 자동 재배정을 안 하는지, `--force`
- 표가 깨져 보여요 → 콘솔 폰트, 코드 페이지
- 배정이 매일 똑같아요 / 매일 달라요 → 라운드 로빈이 어떻게 도는지
- 실수로 지웠어요 → `.bak` 파일

### 7. 명령어 전체 목록

표 하나. 여기까지 온 사람은 이미 개념을 아는 사람이므로 간결해도 됩니다.

### 8. 설정 파일 직접 고치기

고급 사용자용. **뒤에 둡니다.** 앞에 두면 초보자가 겁먹습니다.

## 톤 규칙

- 명령형으로 씁니다. "~할 수 있습니다" 보다 "~하세요".
- 전문 용어를 쓸 거면 그 자리에서 한 문장으로 풀어씁니다. 각주나 용어집으로 미루지 마세요.
- 화면 출력은 실제로 복사한 것만 씁니다. 지어내면 반드시 어긋납니다.
- 경고는 겁주지 말고 이유를 답니다. "지우지 마세요" 가 아니라 "이 폴더에 배정 기록이 들어 있어서, 지우면 과거 이력이 사라집니다".
- 한 문단은 세 문장을 넘기지 않습니다.
